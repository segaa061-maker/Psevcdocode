# Создатель не несет ответственность за злоупотробление данного инструмента . 
Данный инструмент создан в образовательных целях . создатель tg @miohaze  
(инструмент также создан ради юмористических и еще раз в образовательных целях.
Инструмент создан для того что бы доставать дампы из выбранных файлов
С помощью команд таких как /reversT и /dump . 
После запуска вы автоматически соглашаетесь на условия использования. 
также оно - 
разбирает PE: заголовки, архитектура, секции, RVA/размеры/права/энтропия;
импорты, экспорты, ресурсы, Rich header, PDB-путь, Authenticode-подпись, imphash, определение упаковщика;
тянет ASCII/UTF-16 строки, overlay, .NET-метаданные (CLR-версия, флаги — без IL-декомпиляции);
для процесса: minidump, дамп модулей из памяти, строки из памяти;
складывает отчёт report.txt / report.html и файлы в ZIP. 
То есть это рекогносцировка + дампы, а не восстановление исходника. Реальная декомпиляция — это IDA/Ghidra/Binary Ninja (нативные бинари), dnSpy/ILSpy (.NET), x64dbg для динамики. Дампы и строки из /reverseT как раз удобно туда загружать. 
Хорошего вам использования также не злоупотребляйте (нет)
